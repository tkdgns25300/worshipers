- **홈 목록 = 아젠다 타임라인**(`app/home-view.tsx`): 주 구분 헤더(`이번 주`/`다음 주`/`6.15–6.21` 범위) + 왼쪽 날짜 축(일자·요일, **점은 제거**). 그룹핑 `lib/queries.ts groupAgendaWeeks(list, today)`.
- **카드 = 예배권 티켓**(`components/gathering/agenda-card.tsx`) — **반응형**:
  - 모바일(<sm): 시간 스텁 + 본문(eyebrow에 D-day, 장소 줄에 지역). 2단.
  - 태블릿(sm~lg): + 오른쪽 **D-day·지역 떼는 스텁**. 3단.
  - 데스크톱(lg+): + 본문 오른쪽 **팀 블록**(로고 40px·팀명·자세히)으로 넓은 폭 채움.
  - 구성: 왼쪽 시간 스텁(AM/PM+세리프 큰 시간) · 양쪽 천공 노치 · 무료/등록은 조용한 한 줄. props `{ g, team, status, today }`.
- **필터**(`home-view.tsx`): 카테고리 칩(가로 스크롤) + **「필터(n)」 패널**[팀 검색+체크박스 · 지역 · 기간 프리셋 · **날짜 기간 `from`~`to`** · 무료만] + 선택칩. 데스크톱=팝오버, 모바일=바텀시트. 상태=URL 파라미터.
- **카드 2종 공존**: 홈=`AgendaCard`(티켓), **팀 상세(`teams/[id]`)는 아직 `GatheringCard`(캘린더 타일)** — 통일 미정.

## 다음 할 일 — 집회 상세 페이지 재설계

> 사용자 의도 = "여기 **갈 수 있나? 어떻게 가고 어떻게 들어가지?**" (CLAUDE.md "갈 수 있게": 언제·어디서·누가·어떻게(참석), 대상 제외)

**확정된 정보 구조(IA) — 위→아래 순서**
1. 헤더(티켓 헤더): 팀·카테고리·상태/D-day · 제목
2. **입장권 블록(핵심, 티켓 스타일)**: 일시 + 장소 + **등록하기/현장참석 CTA** + 길찾기 — 메타포가 사는 곳
3. **오시는 길·참석 안내**: 주소 + **길찾기 버튼(주소→카카오/네이버 지도 검색 URL 자동 생성, 데이터 추가 0, 링크아웃)** + 교통·주차·입장시각(`note` 기반 표시, **새 필드 최소화**)
4. 누가 함께: 게스트·협력팀(디렉터리 팀이면 링크)
5. 온라인 송출(있으면)
6. 정보 출처(공식 공지, **재호스팅 금지 — 링크아웃**)
7. 주최 팀 카드 → 팀 페이지
8. 광고 슬롯 **제거**(후원 중심 결정)

**핵심 개선 포인트**: ⓐ **길찾기 자동 링크**(지금 `mapUrl` 있을 때만 → 주소로 자동) ⓑ `note` 덩어리를 참석 안내로 구조화 표시 ⓒ 등록 마감 임박 시급성 강조 ⓓ **티켓 메타포 통일**(목록=티켓 미리보기 / 상세=입장권).

**진행 방식(확정)**: 비주얼 언어 이미 잠김 → **통짜 목업 1개**로 전체 흐름 확정(입장권 블록만 2안 비교 + **엣지케이스 렌더**: 정기예배·등록필요+마감·다중일 컨퍼런스·티저 미정·온라인) → 확정 후 **한 번에 구현**(길찾기 자동 링크 포함) → 실페이지 미세조정 → 커밋. (섹션별 목업은 비효율 — 언어 정해졌고 상세는 세로 흐름이 본질)

**현재 상세 페이지(`app/gatherings/[id]/page.tsx`)**: 정보 행 나열형 + `GatheringActions`(등록/공유 CTA, 클라이언트) + `TeamCard` + `Event` JSON-LD. 재작업 대상.
