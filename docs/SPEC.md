# Worshipers — 기획서 (WHAT)

> 아키텍처·컨벤션은 [`../CLAUDE.md`](../CLAUDE.md), 데이터 모델은 [`DATA.md`](./DATA.md), 작업 순서는 [`ROADMAP.md`](./ROADMAP.md). 이 파일은 **페이지·기능·UX·수익 배치·SEO 명세**만 담는다.

## 개요

- **한 줄 설명**: 한국 기독교 찬양집회 일정·장소·등록 정보 큐레이션
- **타겟 사용자**: 집회에 참석하고 싶은 크리스천 (특히 청년·대학·중고등부). "이번 달 위러브 언제 어디서 하지?"를 해결
- **타겟 시장**: 한국 (국내 우선)
- **1순위 가치**: 수익보다 **기독교인에게 도움**. 흩어진 정보를 한곳에서, 빠르게, 정확하게
- **수익 모델**: 디스플레이 광고(카카오 애드핏 우선, 정보 안 가리는 선) + 후원(도네이션). 제휴/스폰서는 Phase 3 옵션
- **데이터**: 관리자 수동 큐레이션 (DATA.md)
- **용어(UI 라벨)** *(확정)*: 팀=**예배팀**, 개별 항목 일반명사=**모임**(항목은 카테고리명으로 표기: 정기예배·기도모임 등). 데이터 식별자는 영어(`Team`/`Gathering`). "지난 집회 보기"→**"지난 모임 보기"**로 통일. SEO 메타/타이틀엔 '집회·일정' 검색어 포함(노출 손실 방지).

## 핵심 사용자 흐름

1. (검색/직접 방문) → 홈에서 **다가오는 집회**를 날짜순으로 본다
2. 팀·지역·기간으로 좁힌다
3. 집회 카드 클릭 → 상세에서 **언제·어디서·등록 방법** 확인
4. **공식 등록/안내 링크**로 이동 (우리는 안내, 등록은 원본에서)

## 페이지 (MVP)

> **로그인·계정·알림 없음** (읽기 전용 큐레이션). 디자인 시안의 우상단 프로필·종(알림)·`저장됨`은 MVP 제외 — "MVP 범위 밖" 참조.

### 0. 공통 (헤더·푸터)

- **헤더**: 로고 워드마크 · `둘러보기`(홈) · 검색바(클라이언트 필터). *(프로필·알림 없음)*
- **푸터**: 후원하기(토스) · 문의(mailto) · 개인정보처리방침(광고 시) · 정보 정정·삭제 요청
- **모바일**: 하단 탭(홈 · 검색 · 소개)

### 1. 홈 — 다가오는 집회 목록 (`/`)

서비스의 심장. 진입 즉시 "다가오는 집회"가 날짜 가까운 순으로 보인다.

- **상단**: 히어로(타이틀 + 한 줄 소개) + 검색바 + 필터바
- **검색**: 모임·예배팀·지역 텍스트 검색 — **클라이언트 사이드 필터**(번들 데이터, 백엔드 없음). 홈은 **히어로 검색만**(헤더 검색과 중복 금지), 내부 페이지는 헤더 검색
- **필터** (URL params로 상태 유지 → 뒤로가기 복원) — 카테고리 칩 외 **팀·지역·기간·무료도 실제 컨트롤로 노출**(모바일은 "필터" 시트로 접힘):
  - **카테고리 칩**: 전체 / 정기예배 / 연합예배 / 거리예배 / 수련회 / 기도모임 / 절기예배 (DATA.md `GatheringCategory`)
  - 팀 (다중 선택)
  - 지역 (시·도 — DATA.md `REGIONS`, "온라인" 포함)
  - **기간 (이번 주 / 이번 달 / 전체)** — 필수 (이번 주=7일 이내, 이번 달=31일 이내)
  - 무료 여부 (전체 / 무료)
- **정렬·그룹**: 날짜 가까운 순. 날짜 버킷으로 그룹(오늘 → 이번 주 → 이후) + 그룹별 건수
- **집회 카드** (한눈에 판단):
  - 팀명 + 팀 이미지(있으면)
  - 집회 테마/타이틀(있으면)
  - 날짜·시간, 장소명 + 지역 배지
  - 상태 배지: `예정` / `오늘` / `등록마감` / `종료` (lib/gathering-status)
  - 무료/유료 표시
- **종료된 집회**: 기본 숨김. "지난 집회 보기" 토글로 노출 (날짜 먼 과거순)
- **빈 상태**: 필터 결과 없을 때 "조건에 맞는 다가오는 집회가 없어요" 안내

### 2. 집회 상세 (`/gatherings/[id]`)

- **헤더**: 팀명·테마·상태 배지
- **핵심 정보 블록** (가리지 않고 명확히):
  - 일시 (날짜 + 시작/종료 시간)
  - 장소 (이름 + 주소 + 지도 링크 — 외부 지도로 링크 아웃)
  - 입장 (무료/유료, 가격)
  - 사전 등록 (필요 여부 + **공식 등록 링크** + 마감일)
  - 게스트/협력팀(있으면), 온라인 송출 링크(있으면)
- **주요 액션(CTA)** — 상태별 분기:
  - 등록 필요 + 열림 → **"등록하기"**(`registration.url`)가 메인 버튼
  - 등록 필요 + 마감 → **"등록마감"**(비활성)
  - 등록 불필요 → 메인 액션은 **공유**, 출처는 보조
- **공유**: URL 복사/공유 버튼 (친구에게 보내기)
- **출처**: 공식 공지(`sourceUrl`) 링크는 **페이지에 한 곳만** (중복 금지) — 신뢰·존중
- **주최 팀 카드**: 팀 상세로 이동
- **SEO**: schema.org `Event` JSON-LD, OG 태그
- (Phase 2) 셋리스트, 후기

### 3. 찬양팀 디렉토리 (`/teams`) — 권장·fast-follow

- 팀 카드 그리드: 팀명·이미지·한 줄 소개·정기집회 주기·주 활동 지역
- 검색: 팀명
- 정렬: 다가오는 집회가 있는 팀 우선 → 이름순

### 4. 팀 상세 (`/teams/[id]`)

- 팀 소개: 이름·소개·교단/색깔(있으면)·소속/주 활동지·정기집회 주기
- **링크**: 유튜브·인스타·홈페이지·카카오 (있는 것만, 링크 아웃)
- 대표곡(있으면 — 곡명 텍스트만)
- **그 팀의 다가오는 집회 목록** (홈 카드 재사용)
- (Phase 2) 지난 집회 아카이브

### 5. 소개 (`/about`)

- 서비스 목적·운영 주체
- **운영 문구 일관성**: '비영리'처럼 오해 소지 있는 표현 대신 "독립적으로 운영되는 큐레이션(광고·후원으로 운영)"으로. 상단 소개와 하단 funding 문구를 일치
- **정보 정정/삭제 요청 안내** (사역팀이 자기 정보 수정 요청할 연락처) — 존중·법적 안전
- **문의**: `tkdgns25300@naver.com` (mailto)
- **후원** 버튼: 토스 송금 링크/QR (`constants` — 승인 불필요·대중적)

### 6. 개인정보처리방침 (`/privacy`)

> 로그인·수집 폼이 없어 *우리가 직접 모으는* 개인정보는 없지만, **광고 네트워크(카카오 애드핏/AdSense 등)·GA가 쿠키로 데이터를 수집**하므로 필요하다 — 로그인 여부와 무관. 광고 프로그램의 필수 요건이자 쿠키 고지 의무.

- 광고 네트워크(쿠키)·Google Analytics 사용·제3자 데이터 제공·옵트아웃 고지
- **이용약관·환불정책·통신판매업 신고는 불필요** — 계정·결제·재화판매가 없음. 후원(토스 송금)도 전자상거래가 아님

## 수익 배치 원칙 (정보를 가리지 않는 선)

> 1순위는 사용자 도움. 광고가 핵심 정보(일시·장소·등록 링크)를 가리거나 클릭을 방해하면 안 된다.

- **디스플레이 광고 슬롯** (카카오 애드핏/AdSense — `components/ads/`):
  - 홈 목록 **인피드**(카드 N개마다 1개) + 페이지 **하단**
  - 집회 상세는 **핵심 정보 블록 아래**에만 (상단·정보 중간 삽입 금지)
  - 모바일에서 고정 하단 띠배너 금지 (정보 가림)
  - 실제 노출은 **승인 후**. 미승인 시 슬롯 비표시
- **후원 버튼**: about + 푸터에 은은하게. 강요·모달 X
- **제휴/스폰서**(Phase 3): 트래픽 확보 후 "추천 집회" 스폰서 슬롯 — 광고임을 명시

## SEO / 분석

- `generateMetadata` 전 페이지 (title·description·OG·Twitter)
- `app/sitemap.ts` · `app/robots.ts`
- JSON-LD: 집회 = `Event`(startDate·location·offers·url), 팀 = `Organization`/`MusicGroup`, 홈 = `WebSite`
- `<html lang="ko">`, 정식 URL은 `NEXT_PUBLIC_SITE_URL`
- Google Search Console + GA4(`NEXT_PUBLIC_GA_ID`)

## 디자인 방향

> 상세 비주얼·브랜드·컴포넌트·목업 방향은 [`DESIGN_BRIEF.md`](./DESIGN_BRIEF.md). 여기는 기능적 디자인 요구만.

- **차분하고 신뢰감 있는 톤.** 화려함보다 정보 가독성 우선
- **모바일 퍼스트** — 사용자는 주로 폰으로 집회 정보를 찾는다
- 상태 배지 컬러 코딩 일관: 예정(기본) / 오늘(강조) / 등록마감·종료(흐림)
- 다크모드(선택, Phase 2)

## 비기능 요구

- **정확성 > 완전성**: 불확실한 정보보다 검증된 출처(`sourceUrl`) 있는 것만 노출
- **속도**: 정적 페이지 — CDN 직접 서빙
- **존중**: 사역팀 저작물 재호스팅 금지, 정정/삭제 요청 창구 제공

## MVP 범위 밖 (Phase 2+)

**로그인·계정·알림(푸시)** · 셋리스트/곡 정보 · 지도 임베드 · 후기/사진 · 제보 폼 · 좋아하는 팀 알림 · 캘린더(.ics) 구독 · 다국어. 상세는 ROADMAP.

> **로그인 없음**: 읽기 전용 큐레이션이라 계정·인증 불필요 → 디자인의 우상단 프로필·종(알림) 제외. **저장됨(찜)**도 MVP 제외 — 원하면 Phase 2에서 `localStorage`로 로그인 없이 구현(기기 한정).
